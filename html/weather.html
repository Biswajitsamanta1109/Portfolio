Weather Monitoring



A weather monitoring system using a DHT11 sensor and ThingSpeak operates by having a microcontroller (like ESP32) read temperature and humidity data from the sensor. The microcontroller then connects to a local Wi-Fi network and pushes the data to ThingSpeak over the internet, which plots it in real-time.

Working

1. Sensing (DHT Sensor)

The DHT sensor continuously measures the surrounding air's temperature and humidity. It converts these physical environmental conditions into digital signals.

2. Processing (ESP32)

The ESP32 microcontroller acts as the "brain." It reads the digital signals from the DHT sensor at regular intervals and processes the data into readable temperature and humidity values.

3. Connectivity (Wi-Fi)

Using its built-in Wi-Fi module, the ESP32 connects to your local wireless network, granting it access to the internet.

4. Cloud Communication (HTTP/API)

The ESP32 securely transmits the processed temperature and humidity values to the ThingSpeak Cloud platform via HTTP requests, using a unique channel Write API key.

5. Visualization (ThingSpeak)

ThingSpeak receives the data, stores it in a cloud database, and automatically plots real-time line graphs so you can monitor environmental changes over time from anywhere.
